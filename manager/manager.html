收藏范围

仅允许收藏下列网址。域名规则会同时匹配它的所有子域。

支持完整网址、*.example.com（子域）、example.com/docs（路径前缀）、*（允许全部）。

解析规则

扩展不内置站点规则。导入 JSON 规则后，在允许的网站上点工具栏图标即可自动提取字段。

规则按 matches 匹配域名（含子域），字段来源支持 label / meta / css / url / derive；可选 searchUrl 模板（{code} / {title}）用于重新定位片源。

同步设置

把收藏推送到中间服务（推荐）或直接推到设备。中间服务保存最新快照，设备打开时再拉取。

本机中间服务：http://127.0.0.1:8789；远程中间服务：https://主机/favour（不含 /api/items）。设备填 App 显示的接收地址。

导入备份

「合并导入」只补充新条目；「覆盖恢复」会清空现有数据并用备份替换。

备份设置

定时备份每天自动执行一次。可以保存到系统下载目录，或指定一个文件夹（例如 OneDrive 里的目录）。

自动备份文件夹

选择文件夹时如出现权限询问请允许，并尽量勾选“每次访问都允许”；否则定时备份会退回下载目录。
